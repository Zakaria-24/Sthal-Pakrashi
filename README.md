# Sthal-Pakrashi

Website and content dashboard for Sthal Pakrashi Institution School & College.

- [`Public-Website/`](Public-Website/) — the public school website (Next.js); reads all content from the Dashboard's API.
- [`Dashboard/`](Dashboard/) — the CMS and API (Next.js + MongoDB) where staff manage that content.
- `following-resources/` — reference screenshots of the design.

Each app has its own README and `.env.example`; copy it to `.env` and fill in the values before running.
